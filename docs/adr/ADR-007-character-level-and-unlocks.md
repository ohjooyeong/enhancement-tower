# ADR-007: 캐릭터 레벨 도입과 보조 성장·해금

## Status
Accepted Direction — 2026-10-23 사용자 승인. **문서 반영, 실제 구현은 미착수.**

Supersedes: [ADR-005-no-character-level.md](ADR-005-no-character-level.md). 원문은 삭제하지 않고 Superseded 상태로 보존한다.

## Context

기존 무레벨 결정은 장비 강화/RP와 성장축 중복, 환생의 초기화 처리, 무기 교체 제약을 줄이기 위한 것이었다. 사용자는 전투 경험과 해금의 성장감을 추가하되 장비 강화가 주 전투력 성장축이라는 원칙을 유지하도록 변경했다.

## Decision

- 몬스터 처치 EXP와 상한이 있는 캐릭터 레벨을 도입한다. 레벨은 기본 능력치의 보조 성장과 콘텐츠·스킬 해금을 맡는다.
- 환생 후에도 캐릭터 레벨을 유지하며 RP는 별도 영구 성장이다. 기존 최고층 기반 환생 조건을 레벨 조건으로 바꾸지 않는다.
- 레벨 상한 Lv.50은 우선 검토 후보이며 확정 수치가 아니다. EXP 곡선/보조 스탯/해금 레벨은 미확정이다.
- 퀘스트 완료 시 추가 EXP 또는 보상을 얻을 수 있지만 일반적인 레벨업을 퀘스트 완료에 종속시키지 않는다. 메인 퀘스트는 안내·서사, 성장 퀘스트는 일반 플레이 목표·추가 보상, 업적은 장기 기록·선택적 보상이다.
- 무기가 전투 스타일 중심이며 자동 스킬은2슬롯으로 보완한다. 스킬 해금과 별도 스킬 레벨은 다른 개념이다. 개별 스킬 레벨·PvP·전직 시스템은 이번에 도입 승인하지 않았다.
- 자동 스킬은 보스 수동 집중 방어를 자동 대체하지 않는다. Farming 전용 Rage·레인 없는 자동 이동·고정 카메라·기존 비주얼 목표를 유지한다.

## Consequences and limits

레벨/장비 강화/RP의 역할과 밸런스 비중을 분리해야 하며, 레벨을 환생 후 보존하는 저장·해금 계약이 필요하다. 퀘스트가 없는 상태에서도 기본 EXP 획득/정상 레벨업이 가능해야 한다. 두 자동 스킬의 해금/발동/쿨다운·무기 호환 정책과 첫 검기 후보의 구체 수치는 별도 검토한다.

이번 결정은 코드/Unity 씬/ScriptableObject 구조 변경이나 서버 구현을 승인하는 작업이 아니다. 기존 전투 테스트 결과는 새 성장 시스템을 검증하지 않는다. 상세 상태와 구현 차이는 [29_LEVEL_QUEST_SKILL_SYSTEM.md](../29_LEVEL_QUEST_SKILL_SYSTEM.md), 충돌 해결은 [25_DECISION_REGISTER.md](../25_DECISION_REGISTER.md)를 따른다.
