# 03. Hub & Community

## Status
Accepted Direction

마을/거점은 플레이어가 직접 움직일 수 있는 사회 공간이다.

## 초기 시설
- 탑 입구
- 대장간
- 장비 상점
- 창고
- 환생 제단
- 게시판
- 거래소
- 길드 시설
- 하우징 구역

## 직접 조작
마을에서는 직접 이동 가능.

가능한 사회 기능:
- 장비 외형 표시
- 강화 이펙트 표시
- 다른 유저 캐릭터 확인
- 장비 Inspect
- 칭호/랭킹 표시

## 사회적 과시
강화가 핵심 콘텐츠이므로 고강화 무기를 다른 유저가 시각적으로 확인할 수 있어야 한다.

예:
- +50: 약한 빛
- +100: 무기 잔광
- +150: 특수 파티클
- +200: 강한 오라
- 특정 레전더리: 고유 이펙트

정확한 연출은 아트 단계에서 결정.
