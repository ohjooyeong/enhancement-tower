# 11. Weapon System

## Status
Accepted Structure

## 시즌1 무기군
### 장검
- 중간 공격력
- 중간 공속
- 중간 사거리
- 전방 직접 다중 베기(최대 3명)와 강한 단일 찌르기를 동작별 정의; 주 대상+주변 스플래시 구조는 폐기 (2026-10-22 사용자 승인)
- 균형형 Auto Positioning

### 대검
- 높은 공격력
- 느린 공속
- 넓은 범위
- 장검보다 넓은 직접 타격 범위/대상 수 후보 (구체 대상 수와 콤보는 미확정)
- 높은 넉백
- 적 밀집 지역 선호

## 향후 무기군
- 쌍검
- 단검
- 창
- 활
- 석궁

각 무기군은 단순 스탯뿐 아니라 Preferred Range와 AI 행동도 다르다. 동작별로 준비/유효/회복, 전방 판정, 총 대상 수, 피해·넉백 계수와 표현을 정의한다. 현재 장검의 사선 → 역베기 → 찌르기는 검증용이며 대검/향후 무기에 같은 3타를 자동 적용하지 않는다.

## 시즌1 등급
```text
일반 → 레어 → 에픽 → 유니크 → 레전더리
```

향후:
```text
신화 → 초월
```

## 무기 수
무기군별:
- 일반 4
- 레어 3~4
- 에픽 3
- 유니크 2
- 레전더리 1

전체 약 26~28종.

## 네이밍 규칙
### 일반
기능적이고 현실적.
예: 철제 장검 / 병사의 장검 / 오크제 장검 / 대장장이의 장검

### 레어
지역/소재/세력.
예: 흑철 장검 / 은빛 기사검 / 서리숲 장검 / 붉은 용병검

### 에픽
특별하지만 아직 전설급은 아님.
예: 황혼의 장검 / 심연철 장검 / 월광 기사검

### 유니크
고유 무기명.
예: 벨카인 / 모르엔 / 라그나크 / 벨도르

### 레전더리
짧고 상징적이며 기억하기 쉬운 이름.
예: 적월 / 혈월

중요:
```text
"적월 먹었어?"
"적월 +184야."
```
처럼 실제 대화가 자연스러워야 한다.

## 같은 등급 내 차이
Base Stat 차이는 ±10~15% 내 가이드.

## 개체값
같은 이름의 무기에도 작은 스탯 롤 차이 존재.

## 등급별 특성
- 일반: 기본 스탯
- 레어: 작은 특성
- 에픽: 방향성 있는 특성
- 유니크: 빌드 영향
- 레전더리: 일부 전투 규칙 변화
