# 15. Orbs, Auto Skill & Rage

## 2026-10-23 현재 기준 안내
자동 스킬은 [29](29_LEVEL_QUEST_SKILL_SYSTEM.md)에 따라 **2슬롯**으로 변경됐다. 아래1슬롯 설명은 이전 설계 기록으로 보존한다. 오브는1슬롯이며 Rage와 보스 수동 집중 방어는 별도다. 캐릭터 레벨은 보조 성장/해금이며 스킬 자체 레벨 도입을 뜻하지 않는다. 최신25/29가 우선한다.

## Status
Accepted

## 오브
시즌1 1슬롯. 기본 공격의 성질을 바꾸는 강한 빌드 요소.

반지는 수치/특성 조합, 오브는 공격 규칙 변형에 가깝게 설계한다.

## 자동 스킬
시즌1 1슬롯. 전투 중 자동 발동하며 주기적인 큰 액션과 시각적 사건을 만든다.

## Rage
자동 스킬과 완전히 별개.

### 사용
- Farming: 가능
- Challenge: 불가
- Boss Challenge: 불가
- Offline: 불가
- Auto Rage: 초기 없음

### 역할
유저가 직접 눌러 짧은 시간 개입.

후보 효과:
- 공격속도 증가
- SpawnRate 증가
- SpawnCount 증가
- 공격 행동 적극성 증가

보상 배율을 직접 붙이지 않는다. 더 많이 잡아서 결과적으로 수익이 증가한다.
