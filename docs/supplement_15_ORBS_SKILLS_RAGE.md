# 15. Orbs, Auto Skill & Rage

## Status
Accepted

## 오브
시즌1 1슬롯. 기본 공격의 성질을 바꾸는 강한 빌드 요소.

반지는 수치/특성 조합, 오브는 공격 규칙 변형에 가깝게 설계한다.

## 자동 스킬
시즌1 1슬롯. 전투 중 자동 발동하며 주기적인 큰 액션과 시각적 사건을 만든다.

## Rage
자동 스킬과 완전히 별개.

### 사용
- Farming: 가능
- Challenge: 불가
- Boss Challenge: 불가
- Offline: 불가
- Auto Rage: 초기 없음

### 역할
유저가 직접 눌러 짧은 시간 개입.

후보 효과:
- 공격속도 증가
- SpawnRate 증가
- SpawnCount 증가
- 공격 행동 적극성 증가

보상 배율을 직접 붙이지 않는다. 더 많이 잡아서 결과적으로 수익이 증가한다.
