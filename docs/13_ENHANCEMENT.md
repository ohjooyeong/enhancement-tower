# 13. Enhancement

## Status
Accepted Structure / Numbers v0

## 기본 규칙
- 장비 파괴 없음
- 성공 시 +1
- 일반 실패 시 단계 유지
- 축복 강화 시 +2
- 역행 시 -1

## 실패 보정
실패마다 다음 시도 성공률 +1%p.

예:
```text
10%
실패 → 11%
실패 → 12%
실패 → 13%
```

최대 100%.
성공 시 누적 실패 보정 리셋.

## 축복 강화
성공 후 별도 판정.

v0:
- 성공 중 2~3%

```text
+127 → 성공 → 축복 → +129
```

## 강화 역행
실패 후 별도 판정.

v0:
- 실패 중 1%
- 강화 -1

```text
+127 → 실패 → 역행 → +126
```

역행이 발생해도 실패 보정은 유지.

## 보호권
향후:
- 일반 실패 방지 X
- 역행 방지 O

## 강화 성공률/비용
정확한 성공률 테이블과 강화석/Gold 비용은 시뮬레이션 후 확정.
