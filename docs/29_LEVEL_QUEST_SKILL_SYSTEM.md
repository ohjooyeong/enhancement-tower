# 29. 캐릭터 레벨·퀘스트·자동 스킬 시스템

기준일: 2026-10-23. **방향 승인 / 수치·실행 규칙 일부 미확정 / 실제 시스템 미구현.** 이번 작업은 문서 반영만 수행한다.

[25 최신 결정](25_DECISION_REGISTER.md)이 최우선이며 이번 성장·퀘스트·스킬 범위에서는25 > 본 문서 > 관련 GDD > 이전 supplement/ADR 순으로 해석한다. [ADR-007](adr/ADR-007-character-level-and-unlocks.md)이 [ADR-005](adr/ADR-005-no-character-level.md)를 대체한다. 기존28은 [View 기술 검토](28_VISUAL_DIRECTION_AND_VIEW_REVIEW.md)이므로 덮어쓰지 않고 새 문서 번호29를 사용한다.

## 1. 승인·후보·미정·구현 상태

| 항목 | 상태 | 내용 |
|---|---|---|
| 캐릭터 레벨/EXP | 방향 확정, 미구현 | 몬스터 처치가 기본 EXP 공급원. 레벨 상한 존재, 환생 후 레벨 유지 |
| 레벨 역할 | 방향 확정, 미구현 | 기본 능력치 보조 성장과 콘텐츠·스킬 해금. 주요 전투력 성장축은 장비 강화 |
| 최고 레벨 | 검토 후보 | **Lv.50 우선 검토**, 출시 확정값/코드 기본값이 아님 |
| 퀘스트 | 방향 확정, 미구현 | 메인: 세계관/시스템 안내, 성장: 일반 플레이 목표/추가 보상, 업적: 장기 기록/선택 보상 |
| 퀘스트와 EXP | 방향 확정, 미구현 | 완료 시 추가 EXP 또는 보상 가능. 퀘스트를 미완료해도 전투로 정상 레벨업 |
| 자동 스킬 | 구조 확정, 미구현 | 2슬롯. 무기 중심 기본 전투를 보완하며 보스 수동 집중 방어를 대신하지 않음 |
| 첫 시각적 공격 스킬 | 후보, 미구현 | 검을 휘두르면 전방으로 검기가 날아가 적을 공격 |
| 개별 스킬 수치/장착·발동 규칙 | 미확정 | 이름/범위/관통/피해/쿨다운/강화별 표현, 두 슬롯 해금/발동 순서/중복·무기 제한 |
| 스킬 자체 레벨/전직/PvP | 도입 승인 없음 | 캐릭터 레벨 도입과 별개. 미래 빌드 다양성을 고려하되 현재 시스템을 추가하지 않음 |
| 실제 코드/씬/SO 변경 | 이번 작업 금지 | 문서의 승인이나 후속 계획을 현재 구현으로 표현하지 않음 |

위 표에 없는 구체적인 스킬 성장 방식과 실행 규칙은 미확정으로 남기며, 설계 승인과 구현 완료를 구분한다.

## 2. 성장축과 전투 스타일의 역할

| 축 | 역할 | 다른 축과의 경계 |
|---|---|---|
| 장비 강화 | **주요 전투력 성장** | 레벨/퀘스트 보상으로 강화의 필요성을 대체하지 않음. 기존 파괴 없음/실패 보정 방향 유지 |
| 캐릭터 레벨 | 기본 능력치 보조 성장·콘텐츠/스킬 해금 | 상한 존재, 환생 후 유지. 무기 강화 단계·개별 스킬 레벨·탑 층수와 다름 |
| RP | 환생을 통한 별도 영구 성장 | 레벨을 삭제하거나 레벨업 EXP로 환산하는 결정은 없음 |
| 무기 | 기본 공격 기하·선호 거리·템포·넉백·자동 포지셔닝 등 스타일 중심 | 시즌1 장검/대검 유지. 무기 교체를 전직/직업 고정으로 치환하지 않음 |
| 오브/반지 | 기본 공격 성질/수치·빌드 보완 | 오브1, 반지2. 스킬 슬롯 수 변경이 오브 증가를 뜻하지 않음 |
| 자동 스킬2슬롯 | 자동 행동 조합으로 빌드 보완 | 슬롯별 해금/발동/쿨다운 미정. 기본 공격이나 수동 집중 방어와 별도 |
| 탑 진행 | 현재층·최고층 등 도전 기록 | 캐릭터 레벨과 별개. 기존 환생의 최고층 기준을 레벨 기준으로 바꾸지 않음 |

레벨의 보조 스탯·해금과 RP 보너스가 겹쳐 강화가 부차적이 되지 않는지 후속 밸런스에서 검증한다. 역할 분리가 승인됐을 뿐 비중/공식/수치는 정하지 않았다.

## 3. 경험치·레벨·환생

- 몬스터 처치로 기본 경험치를 얻는다. 퀘스트 완료는 추가 경험치 또는 보상 경로이며, 수락/완료/보상 수령 여부를 일반 EXP 획득이나 정상 레벨업의 필수 체크로 두지 않는다.
- 레벨은 상한이 있다. Lv.50은 우선 검토 후보다. 시작 레벨, 레벨별 필요 EXP, 몬스터별 EXP, 레벨업 보조 스탯, 콘텐츠/스킬 해금표는 미정이다.
- 레벨 자체가 콘텐츠/스킬 해금 조건을 맡는 방향과, 퀘스트 완료가 레벨업을 차단하는 방식은 구분한다. 개별 콘텐츠의 추가 조건은 별도 검토하되 일반 레벨업을 퀘스트 진행에 종속시키지 않는다.
- 환생 후에도 캐릭터 레벨을 유지한다. 레벨을 되돌려 기존 레벨 조건을 취소하지 않는다. 환생 조건은 기존 최고층 기준이며 새 최소 레벨 조건을 임의로 추가하지 않는다.
- 환생 시 부분 EXP·퀘스트 진행/수령 상태·해금 이력의 세부 저장 정책은 미정이다. 오프라인 EXP 정산, 상한 뒤 EXP 처리도 확정하지 않는다.
- 기존 “무레벨/무경험치, 모험가 성장은 RP로만” 결정은 대체됐다. 개별 스킬 레벨과 무기 숙련도 EXP를 함께 도입한 것은 아니다.

## 4. 메인 퀘스트·성장 퀘스트·업적

| 종류 | 목적 | 보상/제약 |
|---|---|---|
| 메인 퀘스트 | 탑·동조·장비 강화·스킬 등 세계관과 시스템 안내 | 완료 시 추가 EXP 또는 보상 가능. 제출 전까지 일반 처치 EXP를 막지 않음 |
| 성장 퀘스트 | 처치·강화 등 일반 플레이 목표와 추가 보상 | 구체 목표/량은 미정. 퀘스트 대기/미완료 때문에 정상 레벨업을 정지하지 않음 |
| 업적 | 누적·장기 기록과 선택적 보상 | 의무 일일 과제나 캐릭터 레벨업 관문으로 바꾸지 않음. 개별 보상 미정 |

[27 스토리북](27_FIRST_ASCENT_STORYBOOK.md)에 짧은 안내 장면 후보를 연결한다. 첫 EXP/첫 스킬 해금 레벨·두 번째 슬롯 개방 시점을 임의로 첫 보스 전후에 고정하지 않는다. NPC·대사·목표·보상 UI·저장 플래그는 모두 후속 작업이며 지금 존재하지 않는다.

## 5. 자동 스킬2슬롯과 전방 검기 후보

현재 장착 설계는 무기1/갑옷1/반지2/오브1/자동 스킬2슬롯이다. 스킬을 장비 아이템2개로 드랍하거나 처음부터2개를 동시에 해금한다는 결정은 아니다. 슬롯별 해금 시점, 스킬 획득 방식, 중복 장착/공용·무기 전용 구분, 무기 교체 시 호환성은 별도 검토한다.

첫 시각적 공격 스킬 후보는 **전방 검기 방출**이다. 검을 휘둘렀을 때 검기가 전방으로 날아가 적을 공격한다. 이름·공격 범위·관통 수·피해량·쿨다운·강화 수치별 이펙트 변화는 미정이다. 장검/대검 제한과 공용/무기 전용 스킬 구분도 확정하지 않는다.

자동 스킬의 동시 준비 시 우선순위, 기본 공격 잠금과의 관계, 개별/공유 쿨다운, 대상 선정, 투사체 수명/속도·적중 기하/중복 적중 제한은 구현 전에 별도 명세가 필요하다. 기존 평타의 가까운3명 베기/1명 찌르기 규칙을 검기 스킬에 자동 복사하지 않는다. 기존 VFX의 검기 모양은 실제 날아가는 검기 스킬 구현이 아니다.

기존 초기 스킬 가정은 별도 스킬 레벨 없이 ATK 연동이었다. 이번 요청은 캐릭터 레벨·해금·자동 스킬2슬롯을 승인했으며 **개별 스킬 레벨/별도 스킬 강화 성장축은 도입 승인하지 않았다**. 필요성과 최종 피해 공식은 별도 검토한다. 미래 PvP/직업에 가까운 빌드 다양성을 고려하되 지금 PvP/전직/새 무기군 시스템을 추가하지 않는다.

보스는 자동 접근·공격 위에 **수동 집중 방어**로 대응하는 규칙을 유지한다. 자동 스킬이 방어 입력을 자동 소비하거나 예고 시점에 자동 회피/무적을 보장해서 이를 대체하지 않도록 설계한다. 일반적인 생존 보조 후보 자체를 이번에 승인/삭제하는 것은 아니며 세부 후보는 별도 검토한다. Rage는 Farming 전용 별도 수동 기능이다.

## 6. 유지되는 기존 결정과 대체 이력

- **유지:** 레인 없는 전방 중심 자유 자동 이동, 동일한 일반전/보스 카메라·이동 구조, 고정 카메라 방향, 기존 평타 기하와 고정 틱, 밀집/발 충돌/후퇴 한계, 보스 집중 방어, Farming 전용 Rage.
- **유지:** 장비 강화가 주요 성장축, 장비 파괴 없음, RP 환생 영구 성장, 시즌1 장검/대검, 오브1, 경제·핵심 성장 결과의 장기 서버 권위 및 현재 프로토타입의 서버 미구현 원칙.
- **대체:** [ADR-005](adr/ADR-005-no-character-level.md)의 캐릭터 무레벨/무EXP를 [ADR-007](adr/ADR-007-character-level-and-unlocks.md)로 대체. 자동 스킬1슬롯은2슬롯으로 변경. 오래된15/21의 오브2 표기는 기존 오브1 기준으로 정합성을 맞췄다.
- **이력 보존:** 기존 ADR-005 원문·대체 상태,10의 과거 무레벨 이유,25의 이전 결정 인용,과거1슬롯 supplement와26의 실제 구현/검증 기록을 남긴다. 과거 기록이 새 설계보다 우선하지 않는다.

비주얼 목표는 유지한다.

> 약 4등신 캐릭터와 입체감 있는 쿼터뷰 환경으로 구성한 2.5D풍 픽셀 아트 RPG. 레인 없는 전방 중심 자유 자동전투를 사용하며 카메라 방향은 고정한다.

이는 시각적 목표다. [28](28_VISUAL_DIRECTION_AND_VIEW_REVIEW.md)과26의2D/3D 비교 구현이 전체3D 기술 채택을 확정한 것은 아니다.

## 7. 현재 구현과 신규 요구사항의 차이

Assets의 실제 C#·정의·테스트·씬 구조와 [26 구현 이력](26_COMBAT_PROTOTYPE.md)을 확인했다. **아래는 신규 요구사항을 아직 충족하지 못하는 목록이며 이번에 구현하지 않는다.**

| 신규 요구사항 | 현재 코드에서 확인한 상태 | 아직 필요한 것 |
|---|---|---|
| 레벨/상한/EXP/보조 능력치·해금 | `Assets/Scripts/Combat/CombatSimulation.cs`의 Fighter는 전투 HP/공격/방어/공격 상태 등만 보유. 독립 영구 성장 모델 없음 | 레벨·EXP 상태/곡선/해금·스탯 반영 계약과 검증 |
| 처치 EXP 지급 | `StageEncounter.Kills`는 Spawned와 생존 수의 차이로 보여주는 한 판 처치 집계 | 처치 식별/일회 지급/경험치 보상·저장 연결. 킬 카운트가 EXP 지급을 뜻하지 않음 |
| 메인/성장 퀘스트·업적 | 실제 퀘스트 정의·목표 판정·진행/수령 상태·중복 방지·보상 연결 없음 | 퀘스트와 EXP 독립성, 목표/보상/진행 저장 및 안내 UI |
| 자동 스킬2슬롯 | 기본 콤보/조건부 돌파는 있지만 자동 스킬1개 실행기조차 별도 구현돼 있지 않음 | 스킬 소유·해금/장착2슬롯과 일정·우선순위·쿨다운·전투 행동 연결 |
| 날아가는 전방 검기 | Presentation의 근접 검기와 판정 안내는 View. `AttackKind`에는 별도 검기 스킬/투사체 실행 모델 없음 | 정의·이동/수명·기하 적중·피해·관통·표현과 테스트 |
| 무기 중심 빌드 | 장검 실험 콤보/거리/넉백은 존재하나 장검/대검별 프로필 전환이나 스킬 호환 실행은 없음. 후속 [30](30_EQUIPMENT_ENHANCEMENT_PROTOTYPE.md)에 기본 무기/방어구 장착·강화 세션이 추가됨 | 장비/무기 프로필·스킬 조합·전환 정책. 대검 GDD가 곧 구현은 아님 |
| 환생 뒤 레벨 유지 | 실제 환생 처리·레벨/퀘스트 저장·지속 성장/해금 계층 없음 | 환생/저장 계약·복원·레벨 보존 검증 |
| UI·데이터 정의·회귀 | 기존 SO는 콤보/전술/피해/빠른 적/스테이지용. HUD는 전투·보스·방어·View 비교용 | 레벨/EXP/퀘스트/스킬2슬롯 표시·정의·검증. 현재 전투 테스트 통과는 이 기능 검증 아님 |

수동 집중 방어는 기존 구현이 있지만 자동 스킬 실행기가 없으므로 “자동 스킬과 함께 방어가 유지됨”을 검증 완료했다고 표현하지 않는다. 두 시스템의 공존 회귀는 후속 구현 때 필요하다.

## 8. 미확정 항목과 구현 계획의 분리

**미확정:** Lv.50 채택 여부, 시작 레벨, EXP 곡선/지급량/오프라인 처리/상한 이후 정책, 보조 스탯과 강화·RP 비중, 해금표, 퀘스트/업적 목표와 보상·저장, 슬롯별 개방/장착/스케줄, 스킬 자체 성장 필요성, 검기 전체 수치·무기 제한·강화별 이펙트. 기존17의Day30/공격력/재등반 목표도 새 성장축과 함께 재검증한다.

**후속 구현 계획 제안(이번에 착수하지 않음):** 우선 순수 성장 모델에서 테스트용 EXP로 퀘스트 없이 레벨업/상한/환생 보존을 검증할 작은 단위를 명세한다. 이어 처치 지급/저장 연결, 퀘스트 하나의 추가 보상, 스킬 하나의 기하·피해를 검증한 후2슬롯 조합을 다룬다. 이 순서는 검토 제안이며 최종 수치나 구현 착수 승인이 아니다.

영구 성장과 보상은 기존 서버 권위 원칙에 맞춰 나중에 검증하되 현재 서버/API/백엔드를 만들지 않는다. 정적 SO 정의를 실행 상태/저장 데이터로 변형하지 않는다. 신규 스키마·씬·전투 코드는 별도 구현 요청 전 변경하지 않는다.

## 9. 이번 문서 작업 검증 범위

- 대상 GDD/스토리북/AGENTS/README와 기존 보조 문서의 무레벨·스킬1슬롯 충돌을 확인하고 현재 규칙 또는 명시된 이력으로 분류한다.
