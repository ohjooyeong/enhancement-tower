# 04. Combat

## Status
Accepted Direction

탑 안에서는 직접 이동 조작을 하지 않는다.

캐릭터는 타겟 탐색, 자동 접근, 공격, 이탈, 재배치를 수행한다.

## 기본 흐름
```text
SEARCH
→ MOVE TO RANGE
→ ATTACK
→ REPOSITION
→ REPEAT
```

## 공격 판정
FPS와 독립해야 한다.

- 고정 시뮬레이션 시간으로 준비 → 타격 유효 시간 → 회복을 진행한다. 렌더 FPS/검기 프레임은 판정 기준이 아니다.
- 공격 간격은 동작별 준비+유효+회복과 AI의 재탐색/재배치 시간을 포함한다. 단순 `Attack()` 1회 호출을 유효 시간 전체 판정의 대체로 사용하지 않는다.

## 기본 공격 (2026-10-22 사용자 승인 변경)

이전 주 대상 100% + 주변 약 35% 클리브/스플래시 구조를 폐기한다.

- 베기: 플레이어 전방 범위 안의 가까운 적 **총 최대 3명**에게 같은 기본 피해. 주 대상 우선 보너스나 랜덤 선택은 없다. 각 대상 방어는 개별 적용.
- 찌르기: 좁은 전방 범위의 가까운 적 **1명**에게 더 강한 기본 피해.
- 공격마다 준비 → 유효 타격 시간 → 회복을 구분한다. 유효 시간에 새로 들어온 적도 남은 대상 수 안에서 피격한다. 적 한 마리는 같은 동작에서 최대 1회, 전 유효 시간을 합쳐 대상 수 제한을 지킨다. 각 유효 틱에서 아직 맞지 않은 범위 안의 가까운 적을 고르며, 이미 적중한 대상을 나중에 들어온 적으로 교체하지 않는다. 거리가 같으면 생성 순서로 결정한다.
- AI가 조준할 상대는 거리·위협·남은 HP를 반영한 확률 가중치로 고를 수 있다. 이는 아래 실제 타격 공간의 가까운 순 피격 규칙과 구분한다.
- 공격 시작 시 방향을 고정하며 타격 범위는 플레이어 기준이다. 맞은 몬스터 주변으로 번지는 스플래시가 아니다.
- 콤보별 범위·대상 수·피해·준비/유효/회복 시간·넉백·표현을 별도 정적 데이터로 정의한다. 실행 중 체력/적중 기록/콤보 단계는 별도 런타임 상태다.
- 첫 장검 실험은 사선 베기 → 반대 사선 베기 → 찌르기. 3타 고정 순서/피해 1.0·1.0·1.8배/넉백 계수는 실험 가정이며 최종 수치가 아니다. 평소 콤보에는 신체 돌진이 없으며, 아래 조건부 돌파를 별도로 사용한다.

## 조건부 돌파 (2026-10-22 사용자 승인)

- 포위/벽으로 주변 다수 방향이 일정 시간 막혔을 때만 공격 회복 후 시도한다. 기본 콤보를 랜덤으로 바꾸거나 공격 중 취소하지 않는다.
- 돌파 베기는 좁은 전방의 최대 3명을 밀어낸 뒤 회복 구간에 제한된 거리만 전진한다. 벽/플레이어 발 중심 충돌은 그대로 적용한다. 실제 공간이 열리지 않으면 전진을 중단하고 회복 후 재교전한다.
- 기본 콤보 진행 위치를 소비하지 않고 돌파 종료 후 이어간다. 재적용 간격을 길게 두며 피해/경직/무적에 의한 무한 탈출을 보장하지 않는다.
- 실험 기준: 막힘 1.2초, 재사용 8초, 밀림 최대 0.5, 전진 최대 0.4. 준비/유효/회복 .32/.16/.45초. 정적 데이터는 `Assets/Data/CombatTactics.asset`.

DEF는 아래 비율 경감의 기본 생존 스탯이다. 별도 피해 경감·재생·보호막은 장비 특성 후보이며 구현 여부를 구분한다.

## 피해 범위·크리티컬·방어력 (2026-10-22 최소 구현)

- 사용자 요청으로 고정 피해에서 최소/최대 피해와 크리티컬을 지원한다. 장비/성장 연결 없이 순수 전투 모델에 먼저 적용한다.
- 정수 최소/최대 = 기본 공격력 × 최소/최대 계수를 각각 반올림(0.5 올림, 최소 1). 그 사이 정수를 균등 추첨한다.
- 이전 구현 이력: `max(1, 반올림(추첨 공격력 × 동작 피해 계수 × 크리티컬 배수) - 상대 DEF)`. 이 절대 차감은 아래2026-10-23 승인 비율식으로 대체했다.
- 현행: `raw = 반올림(추첨 공격력 × 동작 피해 계수 × 크리티컬 배수)`(최소1), `피해 = max(1, 반올림(raw × K / (K + 상대 DEF)))`. 일반 적중 배수는1, 반올림은0.5 올림이다. 영웅/일반 적/보스 모두 같은 공식을 쓰며 상대 DEF를 적용한다.
- `CombatDamageDefinition.defenseConstant`가 공유 K다. 양의 유한값만 허용하며 초기 비교값은 **20**이다. K가 클수록 같은 DEF의 경감은 약해진다. 최종 K·장비 성장량·층별 적 공격력은 미확정이다. 별도 감소율 상한은 없으며 최소 피해1과 정수 반올림 때문에 높은 DEF/작은 피해에서는 여전히1이 나올 수 있다.
- K20에서 DEF20/40/60은 반올림 전50%/약66.7%/75% 감소다. 감소율 증가 폭은 줄지만 고정 HP의 실질 생존력 `HP × (1 + DEF/K)`는 반올림/최소 피해를 제외하면 DEF에 선형이다. HP와 DEF 동시 성장·회복의 가치까지 자동으로 억제하는 공식은 아니다.
- 보스 집중 방어는 이 계산 이후 보스에게 받는 피해에 추가70% 경감(올림/최소1)을 적용한다. 자동 회피로 대체하지 않는다.
- 자동 회복 포션은 후속 설계/구현이다. 적정 파밍의 방어 후 초당 피해와 회복량/사용 간격, 상위 도전의 회복 초과 압박을 함께 검증한다. 이번에는 몬스터 공격력·장비 HP/DEF 증가량·포션을 변경/구현하지 않는다.
- 각 실제 적중 대상에서 피해와 크리티컬을 독립 추첨한다. 전방 가까운 3명/찌르기 1명의 공간 판정·동일한 기본 피해 계수는 유지하되, 개별 난수/방어에 따라 최종 피해는 달라진다. 크리티컬이 추가 대상/추가 적중을 만들지 않는다.
- 시드 기반 피해 난수는 이동/조준 선택 난수와 분리한다. 같은 시드·초기 설정·입력은 렌더 FPS와 무관하게 재현한다. 체력 변화에 따른 처치 시점/이후 AI 차이는 자연스럽게 발생할 수 있다.
- 실험 기본값: 피해 85~115%, 영웅 크리티컬 15%, 몬스터 5%, 치명 배수 1.5. DEF 영웅 1/일반 몬스터 0/강한 몬스터 3. `Assets/Data/CombatDamage.asset`에서 조절하며 모두 검증용이다.
- 기대 피해를 추정할 때는 정수 추첨값별 일반/치명 피해에 확률을 곱해 합산해야 한다. 반올림과 최소 피해 때문에 단순 평균 공격력 × 평균 치명 배수는 근사치다. 실제 승률/처치 시간·오프라인 정산은 별도 후속 검증 대상으로, 이번에 구현하지 않는다.

## 보스 제한적 수동 개입 (2026-10-23 사용자 승인)
탑의 이동·기본 공격은 자동이다. 보스의 큰 공격은 사용자가 집중 방어로 대응하며 자동 돌진 회피를 기본으로 제공하지 않는다. 첫 실험은 .45초 동안 보스 피해70% 감소, 재사용4초, 최소피해1이다. 공격 취소/무적/이동은 없다. 입력은 다음 고정 틱에서 소비하며 재현 조건에 입력 틱을 포함한다. 평타도 방어할 수 있지만 그만큼 큰 공격 때 재사용 대기를 감수한다. Rage와 별개다. 상세 결정은25 참조.

## 레벨·자동 스킬과 기존 전투의 경계 (2026-10-23)

레벨의 보조 능력치와 장비/RP를 전투 수치에 연결할 계획이지만 공식과 반영 시점은 미확정이며 이번에는 계산을 추가하지 않는다. 기본 공격·무기별 선호 거리/타이밍/범위·넉백이 전투 스타일의 중심이다. 자동 스킬은2슬롯으로 빌드를 보완하며 동시 준비 시 우선순위/공격 잠금/쿨다운 규칙은 별도 검토한다.

첫 시각적 공격 스킬 후보인 전방 검기 방출은 기존 근접 베기/찌르기와 별도 스킬이다. 검을 휘둘러 검기가 전방으로 날아가 적을 공격한다는 방향만 정했으며 이름·범위·관통 수·피해·쿨다운·강화에 따른 표현 변화는 미확정이다. 기존 검기 모양 VFX가 실제 투사체 스킬 구현을 뜻하지 않으며 평타의 최대3명/1명 규칙을 스킬에 자동 적용하지 않는다. 실제 판정/고정 틱/중복 적중 규칙은 후속 명세가 필요하다.

자동 스킬이나 레벨 해금이 보스 수동 집중 방어를 자동 발동하거나 자동 회피/무적으로 대체하지 않는다. Rage는 Farming 전용이며 스킬2슬롯과 별개다. 전투/퀘스트 경험치 지급은 영구 성장 계층의 후속 요구사항으로, 현재 공격 판정이나 킬 수 표시만으로 구현된 것이 아니다. [29](29_LEVEL_QUEST_SKILL_SYSTEM.md) 참조.
