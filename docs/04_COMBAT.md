# 04. Combat

## Status
Accepted Direction

탑 안에서는 직접 이동 조작을 하지 않는다.

캐릭터는 타겟 탐색, 자동 접근, 공격, 이탈, 재배치를 수행한다.

## 기본 흐름
```text
SEARCH
→ MOVE TO RANGE
→ ATTACK
→ REPOSITION
→ REPEAT
```

## 공격 판정
FPS와 독립해야 한다.

- 고정 시뮬레이션 시간으로 준비 → 타격 유효 시간 → 회복을 진행한다. 렌더 FPS/검기 프레임은 판정 기준이 아니다.
- 공격 간격은 동작별 준비+유효+회복과 AI의 재탐색/재배치 시간을 포함한다. 단순 `Attack()` 1회 호출을 유효 시간 전체 판정의 대체로 사용하지 않는다.

## 기본 공격 (2026-10-22 사용자 승인 변경)

이전 주 대상 100% + 주변 약 35% 클리브/스플래시 구조를 폐기한다.

- 베기: 플레이어 전방 범위 안의 가까운 적 **총 최대 3명**에게 같은 기본 피해. 주 대상 우선 보너스나 랜덤 선택은 없다. 각 대상 방어는 개별 적용.
- 찌르기: 좁은 전방 범위의 가까운 적 **1명**에게 더 강한 기본 피해.
- 공격마다 준비 → 유효 타격 시간 → 회복을 구분한다. 유효 시간에 새로 들어온 적도 남은 대상 수 안에서 피격한다. 적 한 마리는 같은 동작에서 최대 1회, 전 유효 시간을 합쳐 대상 수 제한을 지킨다. 각 유효 틱에서 아직 맞지 않은 범위 안의 가까운 적을 고르며, 이미 적중한 대상을 나중에 들어온 적으로 교체하지 않는다. 거리가 같으면 생성 순서로 결정한다.
- 공격 시작 시 방향을 고정하며 타격 범위는 플레이어 기준이다. 맞은 몬스터 주변으로 번지는 스플래시가 아니다.
- 콤보별 범위·대상 수·피해·준비/유효/회복 시간·넉백·표현을 별도 정적 데이터로 정의한다. 실행 중 체력/적중 기록/콤보 단계는 별도 런타임 상태다.
- 첫 장검 실험은 사선 베기 → 반대 사선 베기 → 찌르기. 3타 고정 순서/피해 1.0·1.0·1.8배/넉백 계수는 실험 가정이며 최종 수치가 아니다. 평소 콤보에는 신체 돌진이 없으며, 아래 조건부 돌파를 별도로 사용한다.

## 조건부 돌파 (2026-10-22 사용자 승인)

- 포위/벽으로 주변 다수 방향이 일정 시간 막혔을 때만 공격 회복 후 시도한다. 기본 콤보를 랜덤으로 바꾸거나 공격 중 취소하지 않는다.
- 돌파 베기는 좁은 전방의 최대 3명을 밀어낸 뒤 회복 구간에 제한된 거리만 전진한다. 벽/플레이어 발 중심 충돌은 그대로 적용한다. 실제 공간이 열리지 않으면 전진을 중단하고 회복 후 재교전한다.
- 기본 콤보 진행 위치를 소비하지 않고 돌파 종료 후 이어간다. 재적용 간격을 길게 두며 피해/경직/무적에 의한 무한 탈출을 보장하지 않는다.
- 실험 기준: 막힘 1.2초, 재사용 8초, 밀림 최대 0.5, 전진 최대 0.4. 준비/유효/회복 .32/.16/.45초. 정적 데이터는 `Assets/Data/CombatTactics.asset`.
