# 04. Combat

## Status
Accepted Direction

탑 안에서는 직접 이동 조작을 하지 않는다.

캐릭터는 타겟 탐색, 자동 접근, 공격, 이탈, 재배치를 수행한다.

## 기본 흐름
```text
SEARCH
→ MOVE TO RANGE
→ ATTACK
→ REPOSITION
→ REPEAT
```

## 공격 판정
FPS와 독립해야 한다.

```text
if currentTime >= nextAttackTime:
    Attack()
    nextAttackTime += attackInterval
```

## 기본 공격 (2026-10-22 사용자 승인 변경)

이전 주 대상 100% + 주변 약 35% 클리브/스플래시 구조를 폐기한다.

- 베기: 플레이어 전방 범위 안의 가까운 적 **총 최대 3명**에게 같은 기본 피해. 주 대상 우선 보너스나 랜덤 선택은 없다. 각 대상 방어는 개별 적용.
- 찌르기: 좁은 전방 범위의 가까운 적 **1명**에게 더 강한 기본 피해.
- 공격마다 준비 → 유효 타격 시간 → 회복을 구분한다. 유효 시간에 새로 들어온 적도 남은 대상 수 안에서 피격한다. 적 한 마리는 같은 동작에서 최대 1회, 전 유효 시간을 합쳐 대상 수 제한을 지킨다.
- 공격 시작 시 방향을 고정하며 타격 범위는 플레이어 기준이다. 맞은 몬스터 주변으로 번지는 스플래시가 아니다.
- 콤보별 범위·대상 수·피해·준비/유효/회복 시간·넉백·표현을 별도 정적 데이터로 정의한다. 실행 중 체력/적중 기록/콤보 단계는 별도 런타임 상태다.
- 첫 장검 실험은 사선 베기 → 반대 사선 베기 → 찌르기. 3타 고정 순서/피해 1.0·1.0·1.8배/넉백 계수는 실험 가정이며 최종 수치가 아니다. 별도 전진 돌진은 없다.

## 접촉 피해
근접 몬스터가 플레이어와 접촉하면 일정 주기로 피해.
- 약 1초 Tick 후보
- 몬스터별 개별 Tick

## 공격속도
정식 성장축.

Season 1 가설:
- 시작 약 1.0~1.1회/s
- 상한 약 1.5회/s

Season 2 후보:
- 약 2.0회/s

- 추가타가 추가타를 다시 발동하지 않음
