## 레벨·퀘스트·자동 스킬2슬롯 (2026-10-23)

확정 방향은 [29](29_LEVEL_QUEST_SKILL_SYSTEM.md)를 따른다. 다음은 구현 전에 검토할 항목이며 승인된 수치가 아니다.

- 최종 레벨 상한(Lv.50 우선 검토), 시작 레벨, 처치별 경험치와 곡선, 보조 스탯 비중, 상한 도달 후 경험치 처리
- 콘텐츠/개별 스킬/슬롯별 해금 레벨과 조건. 퀘스트 미완료 때문에 정상 레벨업이 막히지 않는지 검증
- 퀘스트 종류별 목표/보상·수령/중복 방지·진행 저장, 성장 퀘스트와 업적의 구체 조건
- 자동 스킬 두 슬롯 해금 순서/시점, 중복 장착/공용·무기 전용 제한, 동시 발동 우선순위와 공격 잠금·쿨다운
- 전방 검기 방출의 이름/기하/사거리/속도/관통 수/개별 적중 제한/피해/쿨다운·강화 단계별 이펙트. 기존 평타 제한을 자동 상속하지 않음
- 별도 스킬 레벨/스킬 강화 성장축의 필요성(이번에 도입 승인하지 않음), 기존 ATK 연동 가정의 최종 공식
- 환생 시 부분 경험치/퀘스트 상태/해금 이력의 처리, 오프라인 경험치 정산과 전투·퀘스트 성장 기록의 권위 경계
- 새 성장축을 반영한 기존 Day30/재등반/RP 가설 재검증. PvP/전직은 현재 구현 범위 밖
