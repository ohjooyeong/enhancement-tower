# 07. Tower Challenge

## Status
Accepted

## 목적
현재 장비/빌드의 최고 도달층 검증.

## 일반층 v0
- 전투시간 약 60초
- 총 약 50마리
- 약 5마리 단위로 여러 번 스폰
- 전멸 시 즉시 CLEAR
- 플레이어 사망 시 FAIL
- Rage 사용 불가

## 층 유형
- 일반
- 군단
- 중장갑
- 러시
- 엘리트
- 보스

## 자동 등반
```text
CLEAR → 다음 층
FAIL → 같은 층 자동 재도전 1회
다시 FAIL → 추천 Farming 구간 이동
```

## 보스
초기:
- 플레이어 자동 이동
- 보스 제한적 이동 가능
- 제한시간
- 고유 패턴 1개 중심

복잡한 액션 패턴 게임으로 만들지 않는다.

## 한 판 프로토타입 (2026-10-22)

- CombatPrototype의 **Stage run**에서 유한 순차 소환을 실행한다. 처음 5마리, 이후 1.2초마다 1마리, 살아 있는 적 최대 8마리, 총 50마리, 제한 60초가 실험 기본값이다. 기존 약 5마리 단위 웨이브를 최종 확정한 것이 아니며, 우선 끊기지 않는 합류/누적 압박 검증을 위해 1마리씩 보충한다.
- 정적 정의는 `Assets/Data/PrototypeStage.asset`; 실행 중 예약/처치/종료는 순수 C# `StageEncounter`가 소유한다. 모든 예약 적을 미리 Fighter/GameObject로 생성하지 않는다. 상단 진입 후보 중 영웅/생존 적과 떨어진 열린 지점을 사용한다. 점유 시 대기하고, 살아 있는 수가 줄면 보충하되 밀린 예약을 한 번에 쏟아내지 않는다. 후보는 출현 지점이며 이동 레인이 아니다.
- 총 소환 완료 + 생존 적 0에서 CLEAR. 소환 예정이 남은 순간적 빈 필드는 계속 SEARCH하며 기다린다. 영웅 사망은 DEFEAT, 시간 초과는 TIME UP으로 구분한다. 마지막 제한 틱의 전체 처치는 CLEAR 우선이며, 사망은 실패 우선이다. 결과 확정 후 전투/소환/타이머를 동결하고 Restart로 같은 모드를 처음부터 시작한다.
- 5/8/12·Wall/Trap 버튼은 기존 단일 군집 비교로 돌아간다. 카메라·자유 이동·영웅 HP/콤보·타입별 피해·넉백 규칙은 공유한다. 적을 처치해도 영웅 HP를 회복/초기화하지 않는다.
- 다음 층/자동 재도전/추천 Farming 이동/인트로·스킵/보상은 아직 연결하지 않았다. 현재는 한 판의 합류·처치·생존·제한 시간을 검증하는 단계다. Rage는 없다.
