# 07. Tower Challenge

## Status
Accepted

## 목적
현재 장비/빌드의 최고 도달층 검증.

## 일반층 v0
- 전투시간 약 60초
- 총 약 50마리
- 약 5마리 단위로 여러 번 스폰
- 전멸 시 즉시 CLEAR
- 플레이어 사망 시 FAIL
- Rage 사용 불가

## 층 유형
- 일반
- 군단
- 중장갑
- 러시
- 엘리트
- 보스

## 자동 등반
```text
CLEAR → 다음 층
FAIL → 같은 층 자동 재도전 1회
다시 FAIL → 추천 Farming 구간 이동
```

## 보스
초기:
- 플레이어 자동 이동
- 보스 제한적 이동 가능
- 제한시간
- 고유 패턴 1개 중심

복잡한 액션 패턴 게임으로 만들지 않는다.
