# 06. Monsters

## Status
Accepted Direction

시즌1은 근접 몬스터 중심.

## 기본 타입
- 슬라임: 기준형
- 박쥐: 빠른 접근
- 오크: 느리지만 높은 접촉 피해
- 갑옷병: 높은 DEF
- 거대몹: 높은 HP / 넉백 저항
- 광전사: HP 감소 시 가속
- 분열형: 사망 후 작은 적 생성
- 방패형: 첫 N회 피해 감소
- 흡혈형
- 자폭형

## 이동
몬스터는 플레이어 현재 위치를 추적한다.

## 충돌
- 몬스터끼리 겹침 허용
- 물리 길막 최소화
- 약한 시각적 separation 가능

## 층 구성
초반은 신규 몬스터 학습용 단일/테마형 비중을 높이고 중반 이후 조합형 층을 늘린다.

## 원거리 몬스터
Auto Positioning 안정화 후 궁수/마법사/투사체 적을 검토한다.
