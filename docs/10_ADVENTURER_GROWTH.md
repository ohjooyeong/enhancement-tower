# 10. Adventurer Growth

## Status
Accepted

## 캐릭터 레벨
사용하지 않는다.

이유:
- 장비 강화와 성장축 중복
- 환생 시 레벨 처리 어색함
- EXP 테이블 불필요
- 무기 자유 교체와 충돌 가능

## 모험가 자체 성장
환생 포인트(RP)로 영구 성장한다.

```text
장비 성장 = 강화/등급/개체값
모험가 성장 = RP
진행 성장 = 층수
```

## 시즌1 RP 성장 카테고리
### 공격 훈련
- 기본 공격 성능 증가
- 모든 무기에 적용

### 생존 훈련
- HP
- DEF

### 기동 훈련
- 이동속도
- 회피

### 전투 숙련
- 공격속도 또는 전투 효율 보조
- 정확한 효과는 밸런스 테스트 후 확정

## 원칙
특정 무기 전용 RP 트리는 초기에 사용하지 않는다.

피해야 할 예:
- 장검 공격력 +20%
- 대검 공격력 +20%

무기 교체 자유를 방해하기 때문.

## 장기 확장
추후 세부 트리를 추가할 수 있다.
