## 오브 후보
- 흡혈
- 넉백
- 기절
- 폭발
- 클리브 확장
- 처형

목표는 단순 최종 피해 증가보다 플레이 스타일 변화.

예:
- 흡혈 + 공속
- 넉백 + 공속
- 폭발 + 클리브
- 기절 + 추가 공격

## 자동 스킬
2026-10-23 사용자 승인: **자동 스킬2슬롯**으로 변경한다. 캐릭터 레벨은 스킬 해금의 성장축이며 두 슬롯 해금 레벨/스킬 획득 방식/중복 장착/발동 순서/개별·공유 쿨다운은 미확정이다. 자동 스킬은 무기 중심 기본 공격을 보완하고 보스 수동 집중 방어를 자동 대체하지 않는다. Rage는 Farming 전용 별도 기능이다.

후보:
- 검기
- 강타
- 낙뢰
- 연속 베기
- 방어형 스킬

기존 초기 가정은 별도 스킬 레벨 없이 ATK에 연동하는 방식이었다. 이번 승인은 캐릭터 레벨·해금·자동 스킬2슬롯이며, 개별 스킬 레벨/스킬 강화 성장축의 신규 도입이나 최종 피해 공식은 승인하지 않았다. 상세는 미확정 검토 항목으로 남긴다.

## 첫 시각적 공격 스킬 후보: 전방 검기 방출
검을 휘두르면 검기가 전방으로 날아가 적을 공격한다. 이름, 범위, 관통 수, 피해량, 쿨다운, 장비 강화 수치에 따른 이펙트 변화는 미확정이다. 장검/대검 사용 제한과 공용/무기 전용 분류도 별도 검토한다. 현재의 근접 검기 VFX는 이 스킬의 투사체·피해 구현이 아니다.

## 변경 이력과 구현 상태
이전 본문의 `오브2 + 자동 스킬1`은 현재 `오브1 + 자동 스킬2`로 대체했다. 오브1은 기존25/AGENTS의 착용 기준을 따르고 자동 스킬2는 이번 승인을 반영했다. 두 슬롯 실행기·스킬 정의·투사체·UI는 아직 없다. 향후 PvP/직업형 빌드 확장 가능성을 고려하지만 현재 PvP/전직 시스템을 추가하지 않는다. [29](29_LEVEL_QUEST_SKILL_SYSTEM.md) 참조.
