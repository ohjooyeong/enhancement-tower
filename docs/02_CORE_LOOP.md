# 02. Core Loop

## Status
Accepted

## 전체 루프
```text
마을/거점
→ 무기·장비·오브·자동 스킬 2슬롯 세팅
→ 탑 Challenge
→ 최고층 갱신
→ 벽/사망
→ Farming
→ 재화 축적·처치 경험치 획득
→ 강화/장비/오브 조정
→ 재도전
→ 환생
→ RP 획득
→ 모험가 영구 성장
→ 재등반
```

## 핵심 성장축
### 장비 성장
- 무기
- 방어구
- 반지
- 강화
- 개체값
- 고유 특성

### 모험가 성장
- 캐릭터 레벨: 전투 경험치, 보조 능력치, 콘텐츠·스킬 해금(환생 후 유지)
- 환생 포인트(RP): 별도 영구 성장
- 공격
- 생존
- 기동
- 전투 숙련

### 진행 성장
- 현재 층
- 최고층
- 환생 횟수
- 시즌 기록

## 캐릭터 레벨과 퀘스트 (2026-10-23 갱신)
상한이 있는 캐릭터 레벨을 도입하고 환생 후에도 유지한다. Lv.50은 검토 후보이며 확정 상한이 아니다. 기본 경험치는 몬스터 처치로 얻으므로 메인 퀘스트가 대기/미완료여도 일반적인 레벨업을 막지 않는다. 퀘스트 완료는 추가 경험치 또는 보상의 경로다.

메인 퀘스트는 세계관과 시스템 안내, 성장 퀘스트는 일반 플레이 목표/추가 보상, 업적은 장기 기록/선택적 보상을 맡으며 필수 반복 루프를 퀘스트 제출로 치환하지 않는다. 레벨은 보조 성장·해금, 강화는 주 전투력 성장, RP는 환생 영구 성장이다. 레벨 해금 조건과 퀘스트 조건은 구분하고 상세 조건은 별도 검토한다.
