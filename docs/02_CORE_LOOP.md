# 02. Core Loop

## Status
Accepted

## 전체 루프
```text
마을/거점
→ 장비 세팅
→ 탑 Challenge
→ 최고층 갱신
→ 벽/사망
→ Farming
→ 재화 축적
→ 강화/장비/오브 조정
→ 재도전
→ 환생
→ RP 획득
→ 모험가 영구 성장
→ 재등반
```

## 핵심 성장축
### 장비 성장
- 무기
- 방어구
- 반지
- 강화
- 개체값
- 고유 특성

### 모험가 성장
- 환생 포인트(RP)
- 공격
- 생존
- 기동
- 전투 숙련

### 진행 성장
- 현재 층
- 최고층
- 환생 횟수
- 시즌 기록

## 캐릭터 레벨
사용하지 않는다.

레벨 경험치 시스템 없이 장비 강화, 층 진행, 환생, RP로 성장 구조를 구성한다.
