# 00. Game Overview

## 시각적 목표 (2026-10-23 사용자 승인)

> 약 4등신 캐릭터와 입체감 있는 쿼터뷰 환경으로 구성한 2.5D풍 픽셀 아트 RPG. 레인 없는 전방 중심 자유 자동전투를 사용하며 카메라 방향은 고정한다.

현대적인 수제 도트를 지향한다. 렌더링 기술은 미확정이며 시각적 목표와 별도로 검증한다. [기술 검토](28_VISUAL_DIRECTION_AND_VIEW_REVIEW.md).


## Status
Accepted

## 게임명
강화의 탑

## 장르
모바일 방치형 RPG + 강화 시뮬레이션 + 자동 전투 빌드 게임

## 핵심 문장
> 죽고, 강화하고, 환생하고, 다시 올라간다.

## 핵심 재미
1. 강화 수치가 계속 쌓이는 성장감
2. 장비 이름과 강화 수치 자체가 자랑거리가 되는 구조
3. 장검/대검 등 무기 타입마다 전투 방식이 달라지는 구조
4. 오브와 스킬 조합으로 빌드를 만드는 재미
5. 환생 후 예전 층을 압도적으로 빠르게 재등반하는 쾌감
6. 방치형이지만 Rage 같은 직접 개입으로 짧은 액션감을 제공
7. 고강화 장비를 마을에서 다른 유저에게 보여주는 사회적 과시

## 목표 UX
유저가 다음과 같은 말을 자연스럽게 하게 만드는 것.
- "적월 +184 찍었다."
- "이번에 유니크 대검 먹었어."
- "이번 환생으로 150층 다시 뚫었다."
- "장검에서 대검으로 계승할지 고민 중."
- "이번 빌드는 흡혈 + 공속이 잘 맞는다."

## 중요한 철학
- 피해 숫자를 지나치게 천문학적으로 키우지 않는다.
- 강화가 핵심 성장축이다.
- 무기 등급만 올라간다고 기존 고강화 장비가 즉시 쓰레기가 되지 않는다.
- 과금은 강력한 성장 가속을 허용하되 핵심 규칙 자체를 과금 전용으로 만들지는 않는다.

## 보스 참여 (2026-10-23)
일반 전투와 파밍은 자동 성장 흐름을 유지한다. 보스는 자동 접근·공격 위에 사용자가 큰 공격에 집중 방어로 대응하는 참여 구간이다. Farming 전용 Rage와 분리하며 수동 이동은 추가하지 않는다.
